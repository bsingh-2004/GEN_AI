## 🚀 Featured Projects

### 🧠 AI Blog Writer with Human Feedback

A multi-agent AI application that generates blog content using dedicated **Researcher, Writer, and Editor agents**.

The workflow includes **human-in-the-loop feedback**, allowing the user to review and improve the research and draft before the final blog is generated.

**Tech Stack:**  
Python • LangGraph • Groq • LLMs • Streamlit • Human-in-the-Loop

---

### 📚 RAG-Based PDF Q&A Chatbot

A Retrieval-Augmented Generation (RAG) application that allows users to upload PDF documents and ask questions based on their content.

The application processes documents through:

`PDF → Text Splitting → Embeddings → Vector Store → Retrieval → LLM → Answer`

**Tech Stack:**  
Python • LangChain • RAG • Hugging Face Embeddings • ChromaDB • Groq • Streamlit

---

### 🗄️ AI-Powered SQL Agent

An AI agent that understands natural-language questions and interacts with a SQL database using LangChain tools.

It allows users to retrieve and work with database information through conversational queries instead of manually writing SQL queries.

**Tech Stack:**  
Python • LangChain • SQL • SQLite • LLMs • AI Agents

Some projects require API keys.

Create a `.env` file in your local project directory:

```text

```

API keys and `.env` files should **never be committed to GitHub**.
